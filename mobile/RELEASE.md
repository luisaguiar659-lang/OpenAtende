# OpenAtende v0.1.0

Primeira versão MVP do aplicativo Android.

## Incluído

- Tela Splash
- Tela de login
- Lista de conversas
- Tela de atendimento/chat
- Estrutura de autenticação
- Estrutura de serviços para API

## Build

Gerar APK:

```bash
flutter pub get
flutter build apk
```

Arquivo gerado:

`build/app/outputs/flutter-apk/app-release.apk`
