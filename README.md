# OpenAtende

Sistema open source de atendimento e automação multicanal.

## Objetivo

Criar uma plataforma moderna para gerenciamento de atendimentos, clientes, bots e integrações.

## Roadmap inicial

- [x] Estrutura inicial do projeto
- [ ] Backend API
- [ ] Dashboard administrativo
- [ ] Sistema de usuários
- [ ] Tickets de atendimento
- [ ] Integração WhatsApp
- [ ] Automações
- [ ] Integrações futuras com outros canais

## Arquitetura planejada

```
OpenAtende
├── backend

```
